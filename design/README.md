# TruckMate Design Workspace

This directory preserves the independent-design process.

## Rule
GPT, Claude, and Gemini must each complete their first design independently, without reading the other two designs.

## Structure
- `independent/gpt/DESIGN_V1.md`
- `independent/claude/DESIGN_V1.md`
- `independent/gemini/DESIGN_V1.md`
- `review-round/` for post-independence learning/revisions
- `final/` for the owner-approved consolidated design

The original independent design files must remain preserved after the review round.
